# Useful-functions

**Author:** Aljaž Ravnikar

Useful random function in Python to make your life easier.

## Content

- **Python modules:** Functions and utilities that can be imported directly using `import <module-name>`.

- **Matplotlib styles:** Custom plot styles based on the default Matplotlib style file.

## Usage

1. Adding directory to the Python PATH

Crerate a `mypath.pth` file, containing the absolute path to this repository directory.

- Windows (Anaconda example):
`~\anaconda3\Lib\site-packages\mypath.pth`

- Linux: 
`~/anaconda3/lib/python3.x/site-packages/mypath.pth`

2. Adding custom Matplotlib styles

Copy the `.mplstyle` file to the Matplotlib style library directory.

- Windows:
`C:\Users\<username>\.matplotlib\stylelib\<StyleName>.mplstyle`

- Linux:
`/home/<username>/.config/matplotlib/stylelib/<StyleName>.mplstyle`

Replace *<username>* and *<StyleName>* with the appropriate values and *x* with Python version.
